<details>
<summary>🛢️ <b>FuelShield</b> — Fuel Monitoring & Theft Detection Platform &nbsp;[<code>LEGENDARY</code>]</summary>

<br/>

Fleet-scale IoT system with real-time fuel visibility and anomaly-based theft detection. ESP32 firmware reads ultrasonic + GPS sensors, publishes over MQTT, and Firebase Cloud Functions handle alert dispatch, event processing, and RBAC dashboards.

**🏆 Impact:** `85%+ reduction in fuel theft` · `Sub-2% sensor accuracy` · `10s GPS refresh rate`

```
Stack: ESP32 · C/C++ · Node.js · Next.js 14 · TypeScript · Tailwind CSS
       Firebase (Auth · Firestore · RTDB · Functions) · Flutter · MQTT · Netlify
```

**Architecture:** `Edge (ESP32 Firmware)` → `MQTT Bridge` → `Cloud Functions` → `WebSocket` → `Dashboard + Mobile`

</details>

```
Stack: Embedded C/C++ · ESP32 · Serial + Wireless Protocols · Fail-safe FSM Design
```

</details>
